# Stage 6 — SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish every page with complete, verifiable SEO: Yoast post meta (focus keyword, title, description, Open Graph, Twitter, schema page type), JSON-LD extensions merged into Yoast's graph, a generated 1200×630 OG image when none is supplied, site Organization data when empty, an on-page audit with a fix loop, and the `protoblocks-seo` skill that infers missing values and flags them.

**Architecture:** WordPress side: `scripts/wp/yoast.php` (writes through `WPSEO_Meta::set_value`, then `wp_update_post` so Yoast rebuilds the indexable) and `scripts/theme-assets/inc/pb-schema.php` (filter `wpseo_schema_graph` merges per-page `_pb_schema` post meta). Node side: `scripts/lib/seo.mjs` (validate + apply + record), `scripts/qa/og-image.mjs`, `scripts/qa/seo-audit.mjs` (rendered-DOM audit). The test site gets a PHP built-in server with a router so integration tests can read real front-end HTML.

**Tech Stack:** Yoast SEO 28.x (`WPSEO_Meta`, filter `wpseo_schema_graph($graph, $context)` with `$context->main_schema_id`, `$context->canonical`, `$context->indexable->object_id/object_type`), WP-CLI, Playwright + sharp (Stage 3).

**Spec:** `docs/superpowers/specs/2026-10-01-site-builder-design.md` (§8 SEO, §7 page completion order)

**Builds on:** Stage 1 state; Stage 2 `createWp`/`loadRuntime`/`WP_SCRIPTS_DIR`, `installThemeAssets` (managed `inc/pb-*.php` loader), test site helpers; Stage 3 `launchBrowser`/`openPage`/`loadRaw`/`rawToPng`, `tests/qa/helpers.mjs`; Stage 4 `importMedia` (`media.mjs`), `artifactsDir`, page `url`/`postId` in state.

Verified on Yoast 28.6: setting `focuskw`, `title`, `metadesc`, `opengraph-title`, `schema_page_type` with `WPSEO_Meta::set_value($key, $value, $postId)` then `wp_update_post(['ID'=>$id])` produces the expected `<title>`, `meta[name=description]`, `og:*` tags and `@type: ["WebPage","AboutPage"]` on the front end.

## Global Constraints

- Yoast keys written (without the `_yoast_wpseo_` prefix, via `WPSEO_Meta::set_value`): `focuskw`, `title`, `metadesc`, `opengraph-title`, `opengraph-description`, `opengraph-image`, `opengraph-image-id`, `twitter-title`, `twitter-description`, `twitter-image`, `twitter-image-id`, `schema_page_type`.
- Title template: the SEO title value may use Yoast vars (`%%sep%%`, `%%sitename%%`); the rendered `<title>` must be ≤ 60 characters.
- Meta description 120–156 characters. Focus keyword: 1–4 words, lowercase.
- `schema_page_type` ∈ `WebPage, ItemPage, AboutPage, FAQPage, QAPage, ProfilePage, ContactPage, MedicalWebPage, CollectionPage, CheckoutPage, RealEstateListing, SearchResultsPage`.
- `_pb_schema` post meta = JSON `{ "webpage": { …props merged into Yoast's WebPage piece }, "pieces": [ …extra schema.org nodes ] }`. Each piece gets `@id = <canonical>#pb-<type>-<index>` when missing; pieces other than `Organization`/`Person`/`Brand` get `isPartOf: {"@id": <main_schema_id>}` when missing.
- Organization (`wpseo_titles`: `company_or_person=company`, `company_name`, `company_logo`, `company_logo_id`; `wpseo_social`: `facebook_site`, `twitter_site`, `other_social_urls`) is only written when `company_name` is empty, unless `--force-organization`.
- OG image: 1200×630 PNG. Source priority: developer-supplied file → generated from the first content section (`#pb-s<n>` lowest `n` that isn't header/footer `inPart`) rendered at 1200 px wide, cover-fit to 1200×630 with top alignment. Imported with alt = page title. Also set as featured image when the page has none.
- Every inferred SEO value is stored in state as `{ value, inferred: true, why }`; provided values as `{ value, inferred: false }`.
- Audit (rendered DOM) checks and severities: `h1-count` (fail ≠ 1), `heading-order` (warn on skipped levels), `kw-title`, `kw-h1`, `kw-first-paragraph`, `kw-description` (fail when missing), `kw-slug` (warn), `title-length` (fail > 60), `description-length` (fail outside 120–156), `img-alt` (fail for any `<img>` without `alt` attribute; empty alt allowed), `internal-link` (warn when 0), `jsonld-parse` (fail), `jsonld-required` (fail on missing required props), `og-tags` (fail when any of og:title/og:description/og:image/og:url missing), `og-image` (fail unless reachable and 1200×630), `canonical` (fail when missing). `pass` = no `fail`.
- Required JSON-LD props: WebPage `name,url`; Organization `name,url`; FAQPage `mainEntity`; Question `name,acceptedAnswer`; Answer `text`; Product `name`; Service `name`; Event `name,startDate,location`; Review `itemReviewed,reviewRating,author`; HowTo `name,step`; BreadcrumbList `itemListElement`.
- Page lifecycle: `building` (sections in progress) → `seo` (all sections `done`/`skipped`) → `done` (audit pass recorded).

## Review Focus

1. **Yoast caches the old values (indexables)** — after apply, the front end must show the new title/description without a manual reindex; integration test in Task 2 reads served HTML.
2. **Developer already configured Organization in Yoast** — never overwritten without `--force-organization`; integration test in Task 2.
3. **Hero shorter than 630 px at 1200 width** — OG image still exactly 1200×630 (padded with the section's background colour); QA test in Task 3.
4. **Pages with multiple `<h1>` (hero + section titles)** — audit fails `h1-count` with the selectors; unit test in Task 4.
5. **Malformed or partial JSON-LD added by a block** — audit reports `jsonld-parse`/`jsonld-required` with the offending type instead of crashing; unit test in Task 4.

```js
import { spawn } from 'node:child_process';

export async function serveSite() {
  const url = 'http://127.0.0.1:8881';
  const up = async () => { try { const r = await fetch(`${url}/`, { redirect: 'manual' }); return r.status < 500; } catch { return false; } };
  if (await up()) return { url, close: async () => {} };
  const proc = spawn('php', ['-S', '127.0.0.1:8881', path.join(SITE_DIR, 'router.php')], { cwd: SITE_DIR, stdio: 'ignore' });
  const start = Date.now();
  while (!(await up())) {
    if (Date.now() - start > 15000) { proc.kill(); throw new Error('test site did not start on :8881'); }
    await new Promise((r) => setTimeout(r, 200));
  }
  return { url, close: async () => { proc.kill(); } };
}
```

- [ ] **Step 3: Write `scripts/theme-assets/inc/pb-schema.php`**

```php
<?php
/**
 * Managed by protoblocks-site-builder — overwritten on every install. Do not edit.
 * Merges per-page `_pb_schema` post meta into Yoast's JSON-LD graph.
 * _pb_schema = {"webpage": {...props for the WebPage piece}, "pieces": [...schema.org nodes]}
 */
if (!defined('ABSPATH')) {
    exit;
}

add_filter('wpseo_schema_graph', function ($graph, $context) {
    if (!is_array($graph) || !isset($context->indexable) || $context->indexable->object_type !== 'post') {
        return $graph;
    }
    $raw = get_post_meta((int) $context->indexable->object_id, '_pb_schema', true);
    $data = is_string($raw) && $raw !== '' ? json_decode($raw, true) : null;
    if (!is_array($data)) {
        return $graph;
    }
    $main_id = $context->main_schema_id ?? $context->canonical;

    if (!empty($data['webpage']) && is_array($data['webpage'])) {
        foreach ($graph as $i => $piece) {
            $types = (array) ($piece['@type'] ?? []);
            if (($piece['@id'] ?? null) === $main_id || in_array('WebPage', $types, true)) {
                $graph[$i] = array_merge($piece, $data['webpage']);
                break;
            }
        }
    }

    $standalone = ['Organization', 'Person', 'Brand'];
    foreach ((array) ($data['pieces'] ?? []) as $n => $piece) {
        if (!is_array($piece) || empty($piece['@type'])) {
            continue;
        }
        $type = is_array($piece['@type']) ? (string) reset($piece['@type']) : (string) $piece['@type'];
        if (empty($piece['@id'])) {
            $piece['@id'] = $context->canonical . '#pb-' . sanitize_key($type) . '-' . $n;
        }
        if (empty($piece['isPartOf']) && !in_array($type, $standalone, true)) {
            $piece['isPartOf'] = ['@id' => $main_id];
        }
        $graph[] = $piece;
    }
    return $graph;
}, 20, 2);
```

```php
<?php
/**
 * Yoast SEO writer. Usage: wp eval-file yoast.php apply <spec.json> | get <postId>
 */
if (!class_exists('WPSEO_Meta')) { fwrite(STDERR, "Yoast SEO is not active.\n"); exit(1); }
$admins = get_users(['role' => 'administrator', 'number' => 1, 'fields' => 'ID']);
wp_set_current_user((int) ($admins[0] ?? 0));
$out = function ($d) { echo wp_json_encode($d, JSON_UNESCAPED_SLASHES) . "\n"; };
$cmd = $args[0] ?? '';

if ($cmd === 'get') {
    $id = (int) ($args[1] ?? 0);
    $keys = ['focuskw', 'title', 'metadesc', 'opengraph-title', 'opengraph-description', 'opengraph-image', 'opengraph-image-id', 'twitter-image', 'schema_page_type'];
    $data = [];
    foreach ($keys as $k) { $data[$k] = WPSEO_Meta::get_value($k, $id); }
    $data['pbSchema'] = json_decode((string) get_post_meta($id, '_pb_schema', true), true);
    $data['organizationName'] = WPSEO_Options::get('company_name', '');
    $data['thumbnailId'] = (int) get_post_thumbnail_id($id);
    $out($data);
    return;
}
if ($cmd !== 'apply') { fwrite(STDERR, "Usage: yoast.php apply <spec.json> | get <postId>\n"); exit(1); }

$spec = json_decode((string) file_get_contents($args[1] ?? ''), true);
$id = (int) ($spec['postId'] ?? 0);
if (!$id || !get_post($id)) { fwrite(STDERR, "Unknown postId.\n"); exit(1); }

$written = [];
foreach ((array) ($spec['meta'] ?? []) as $key => $value) {
    if ($value === null || $value === '') { continue; }
    if (in_array($key, ['opengraph-image-id', 'twitter-image-id'], true)) {
        $url = wp_get_attachment_url((int) $value);
        if (!$url) { continue; }
        WPSEO_Meta::set_value($key, (string) (int) $value, $id);
        WPSEO_Meta::set_value(str_replace('-id', '', $key), $url, $id);
        $written[] = $key;
        $written[] = str_replace('-id', '', $key);
        continue;
    }
    WPSEO_Meta::set_value($key, (string) $value, $id);
    $written[] = $key;
}
if (array_key_exists('pbSchema', $spec)) {
    if ($spec['pbSchema']) { update_post_meta($id, '_pb_schema', wp_slash(wp_json_encode($spec['pbSchema']))); $written[] = '_pb_schema'; }
    else { delete_post_meta($id, '_pb_schema'); }
}
$featured = false;
if (!empty($spec['featuredImageId']) && !get_post_thumbnail_id($id)) {
    $featured = (bool) set_post_thumbnail($id, (int) $spec['featuredImageId']);
}

$org = 'skipped';
if (!empty($spec['organization']['name'])) {
    if (WPSEO_Options::get('company_name', '') === '' || !empty($spec['forceOrganization'])) {
        WPSEO_Options::set('company_or_person', 'company');
        WPSEO_Options::set('company_name', (string) $spec['organization']['name']);
        if (!empty($spec['organization']['logoId'])) {
            WPSEO_Options::set('company_logo_id', (int) $spec['organization']['logoId']);
            WPSEO_Options::set('company_logo', (string) wp_get_attachment_url((int) $spec['organization']['logoId']));
        }
        $socials = array_values(array_filter((array) ($spec['organization']['socials'] ?? [])));
        foreach ($socials as $i => $s) {
            if (str_contains($s, 'facebook.com')) { WPSEO_Options::set('facebook_site', $s); unset($socials[$i]); }
            elseif (preg_match('#(twitter|x)\.com/([^/?]+)#', $s, $m)) { WPSEO_Options::set('twitter_site', $m[2]); unset($socials[$i]); }
        }
        WPSEO_Options::set('other_social_urls', array_values($socials));
        $org = 'set';
    } else {
        $org = 'kept';
    }
}

wp_update_post(['ID' => $id]);
$out(['postId' => $id, 'written' => $written, 'featuredImageSet' => $featured, 'organization' => $org]);
```

```js
#!/usr/bin/env node
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import { createWp, loadRuntime, WP_SCRIPTS_DIR } from './wp.mjs';
import { loadState, updateState } from './state.mjs';
import { importMedia } from './media.mjs';

export const SCHEMA_PAGE_TYPES = ['WebPage', 'ItemPage', 'AboutPage', 'FAQPage', 'QAPage', 'ProfilePage', 'ContactPage', 'MedicalWebPage', 'CollectionPage', 'CheckoutPage', 'RealEstateListing', 'SearchResultsPage'];

export const renderTitle = (t) => String(t).replace(/%%sep%%/g, '-').replace(/%%sitename%%/g, '').replace(/\s+$/, '');
const val = (leaf) => leaf?.value;

export function validateSeo(seo) {
  const errors = [];
  for (const [k, leaf] of Object.entries(seo ?? {})) {
    if (!leaf || typeof leaf !== 'object' || typeof leaf.inferred !== 'boolean') errors.push(`${k}: needs {value, inferred}`);
    else if (leaf.inferred && !leaf.why) errors.push(`${k}: inferred values need a "why"`);
  }
  const kw = val(seo.focusKeyword);
  if (typeof kw !== 'string' || kw !== kw.toLowerCase() || kw.trim().split(/\s+/).length > 4 || !kw.trim()) errors.push('focusKeyword: 1–4 lowercase words');
  const title = val(seo.title);
  if (typeof title !== 'string' || !title.trim()) errors.push('title: required');
  else if (renderTitle(title).length > 60) errors.push(`title: renders to ${renderTitle(title).length} chars (max 60 before the site name)`);
  const d = val(seo.description);
  if (typeof d !== 'string' || d.length < 120 || d.length > 156) errors.push(`description: ${typeof d === 'string' ? d.length : 0} chars (need 120–156)`);
  if (seo.schemaPageType && !SCHEMA_PAGE_TYPES.includes(val(seo.schemaPageType))) errors.push(`schemaPageType: must be one of ${SCHEMA_PAGE_TYPES.join(', ')}`);
  return errors;
}

export function buildYoastSpec({ postId, seo, ogImageId = null, organizationLogoId = null, forceOrganization = false }) {
  const title = val(seo.title);
  const desc = val(seo.description);
  const org = val(seo.organization);
  return {
    postId,
    meta: {
      focuskw: val(seo.focusKeyword),
      title,
      metadesc: desc,
      'opengraph-title': renderTitle(title),
      'opengraph-description': desc,
```

```js
#!/usr/bin/env node
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import sharp from 'sharp';
import { shoot } from './shoot.mjs';
import { loadRaw } from './image.mjs';

export const OG_SIZE = { width: 1200, height: 630 };

export async function ogImage({ url, selector, out, browser }) {
  const tmp = path.join(fs.mkdtempSync(path.join(os.tmpdir(), 'pb-og-')), 'shot.png');
  await shoot({ url, selector, width: OG_SIZE.width, scale: 1, out: tmp, browser });
  const raw = await loadRaw(tmp);
  const img = sharp(tmp);
  fs.mkdirSync(path.dirname(out), { recursive: true });
  if (raw.height >= OG_SIZE.height) {
    await img.extract({ left: 0, top: 0, width: Math.min(raw.width, OG_SIZE.width), height: OG_SIZE.height }).resize(OG_SIZE.width, OG_SIZE.height, { fit: 'fill' }).png().toFile(out);
  } else {
    const i = (raw.height - 1) * raw.width * 4;
    const [r, g, b] = raw.data.subarray(i, i + 3);
    await img.extend({ top: 0, bottom: OG_SIZE.height - raw.height, left: 0, right: 0, background: { r, g, b, alpha: 1 } })
      .resize(OG_SIZE.width, OG_SIZE.height, { fit: 'fill' }).png().toFile(out);
  }
  fs.rmSync(path.dirname(tmp), { recursive: true, force: true });
  return { out, width: OG_SIZE.width, height: OG_SIZE.height, source: { width: raw.width, height: raw.height } };
}

async function main(argv) {
  const a = {};
  for (let i = 0; i < argv.length; i += 2) a[argv[i].replace(/^--/, '')] = argv[i + 1];
  if (!a.url || !a.selector || !a.out) { process.stderr.write("Usage: node og-image.mjs --url U --selector '#pb-s1' --out og.png\n"); process.exit(64); }
  process.stdout.write(`${JSON.stringify(await ogImage({ url: a.url, selector: a.selector, out: a.out }), null, 2)}\n`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(fs.realpathSync(process.argv[1])).href) {
  main(process.argv.slice(2)).catch((e) => { process.stderr.write(`${e.message}\n`); process.exit(1); });
}
```

```js
#!/usr/bin/env node
import fs from 'node:fs';
import { pathToFileURL } from 'node:url';

export const REQUIRED_PROPS = {
  WebPage: ['name', 'url'], Organization: ['name', 'url'], FAQPage: ['mainEntity'], Question: ['name', 'acceptedAnswer'], Answer: ['text'],
  Product: ['name'], Service: ['name'], Event: ['name', 'startDate', 'location'], Review: ['itemReviewed', 'reviewRating', 'author'],
  HowTo: ['name', 'step'], BreadcrumbList: ['itemListElement'],
};

const norm = (s) => String(s ?? '').toLowerCase().replace(/\s+/g, ' ').trim();

function nodesOf(json) {
  const out = [];
  const walk = (n) => {
    if (Array.isArray(n)) return n.forEach(walk);
    if (!n || typeof n !== 'object') return;
    if (n['@type']) out.push(n);
    if (n['@graph']) walk(n['@graph']);
    for (const [k, v] of Object.entries(n)) if (k !== '@graph' && typeof v === 'object') walk(v);
  };
  walk(json);
  return out;
}

export function auditExtract(e, { focusKeyword, ogImageInfo }) {
  const checks = [];
  const add = (id, ok, detail, fix, warnOnly = false) => checks.push({ id, status: ok ? 'pass' : warnOnly ? 'warn' : 'fail', detail, ...(ok ? {} : { fix }) });
  const kw = norm(focusKeyword);

  const h1s = e.h.filter((h) => h.level === 1);
  add('h1-count', h1s.length === 1, `${h1s.length} h1: ${h1s.map((h) => h.selector).join(', ') || 'none'}`, 'Exactly one h1 per page: demote extra section titles to h2 (block tagName/attribute).');
  const skips = e.h.slice(1).filter((h, i) => h.level > e.h[i].level + 1).map((h) => `${h.selector} (h${h.level})`);
  add('heading-order', skips.length === 0, skips.length ? `skipped levels at ${skips.join(', ')}` : 'ok', 'Use consecutive heading levels (h2 under h1, h3 under h2).', true);
  add('kw-title', norm(e.title).includes(kw), e.title, 'Put the focus keyword near the start of the SEO title.');
  add('kw-h1', h1s.some((h) => norm(h.text).includes(kw)), h1s[0]?.text ?? 'no h1', 'Include the focus keyword in the h1 (or pick a keyword the h1 already uses).');
  add('kw-first-paragraph', norm(e.firstParagraph).includes(kw), (e.firstParagraph ?? '').slice(0, 120), 'Mention the focus keyword in the first paragraph.');
  add('kw-description', norm(e.metaDescription).includes(kw), e.metaDescription ?? 'missing', 'Include the focus keyword in the meta description.');
  const slug = (() => { try { return new URL(e.url).pathname; } catch { return e.url ?? ''; } })();
  add('kw-slug', kw.split(' ').every((w) => slug.toLowerCase().includes(w)), slug, 'Consider a slug containing the keyword (ask before changing a published URL).', true);
  add('title-length', (e.title ?? '').length > 0 && (e.title ?? '').length <= 60, `${(e.title ?? '').length} chars`, 'Shorten the SEO title to ≤ 60 characters.');
  const dl = (e.metaDescription ?? '').length;
  add('description-length', dl >= 120 && dl <= 156, `${dl} chars`, 'Rewrite the meta description to 120–156 characters.');
  const noAlt = e.imgs.filter((i) => i.alt === null).map((i) => i.src);
  add('img-alt', noAlt.length === 0, noAlt.length ? `missing alt: ${noAlt.slice(0, 5).join(', ')}` : 'ok', 'Every <img> needs an alt attribute (empty only for decorative images).');
  add('internal-link', e.links.some((l) => l.internal), `${e.links.filter((l) => l.internal).length} internal links`, 'Link to at least one other page on the site (CTA, nav, footer links inside content).', true);

  const parseErrors = [];
  const nodes = [];
  for (const raw of e.jsonld) {
    try { nodes.push(...nodesOf(JSON.parse(raw))); } catch (err) { parseErrors.push(err.message); }
  }
  add('jsonld-parse', e.jsonld.length > 0 && parseErrors.length === 0, parseErrors.length ? parseErrors.join('; ') : `${e.jsonld.length} block(s)`, 'Fix the JSON-LD (check _pb_schema post meta and any block that prints ld+json).');
  const missing = [];
  for (const n of nodes) {
    for (const t of [].concat(n['@type'])) {
      for (const p of REQUIRED_PROPS[t] ?? []) if (n[p] === undefined || n[p] === '' || (Array.isArray(n[p]) && !n[p].length)) missing.push(`${t}.${p}`);
    }
  }
  add('jsonld-required', missing.length === 0, missing.length ? `missing ${[...new Set(missing)].join(', ')}` : 'ok', 'Add the missing properties to the schema pieces.');

  const ogMissing = ['title', 'description', 'image', 'url'].filter((k) => !e.og?.[k]);
  add('og-tags', ogMissing.length === 0, ogMissing.length ? `missing og:${ogMissing.join(', og:')}` : 'ok', 'Set Open Graph values via seo.mjs apply.');
  const oi = ogImageInfo;
  add('og-image', !!oi && oi.ok && oi.width === 1200 && oi.height === 630, oi ? `HTTP ${oi.status} ${oi.width}x${oi.height}` : 'not fetched', 'Generate a 1200x630 OG image (og-image.mjs) and apply it.');
  add('canonical', !!e.canonical, e.canonical ?? 'missing', 'Yoast prints the canonical; check the page is published and Yoast is active.');

  return { pass: !checks.some((c) => c.status === 'fail'), checks };
}

export async function extractPage(page) {
  return page.evaluate(() => {
    const meta = (sel) => document.querySelector(sel)?.getAttribute('content') ?? null;
    const root = document.querySelector('main') ?? document.body;
    const sel = (el) => { const sec = el.closest('[id^="pb-s"]'); return `${sec ? `section#${sec.id} ` : ''}${el.tagName.toLowerCase()}`; };
    const host = location.host;
    return {
      url: location.href,
      title: document.title,
      metaDescription: meta('meta[name="description"]'),
      canonical: document.querySelector('link[rel="canonical"]')?.href ?? null,
      og: { title: meta('meta[property="og:title"]'), description: meta('meta[property="og:description"]'), image: meta('meta[property="og:image"]'), url: meta('meta[property="og:url"]') },
      h: [...document.querySelectorAll('h1,h2,h3,h4,h5,h6')].map((h) => ({ level: Number(h.tagName[1]), text: h.textContent.trim(), selector: sel(h) })),
      firstParagraph: [...root.querySelectorAll('p')].map((p) => p.textContent.trim()).find((t) => t.length >= 40) ?? '',
      imgs: [...document.querySelectorAll('img')].map((i) => ({ src: i.getAttribute('src'), alt: i.hasAttribute('alt') ? i.getAttribute('alt') : null })),
      links: [...root.querySelectorAll('a[href]')].map((a) => ({ href: a.getAttribute('href'), internal: a.host === host && !a.getAttribute('href').startsWith('#') })),
      jsonld: [...document.querySelectorAll('script[type="application/ld+json"]')].map((s) => s.textContent),
    };
  });
}

export async function seoAudit({ url, focusKeyword, out, browser }) {
  const { launchBrowser, openPage } = await import('./browser.mjs');
  const { default: sharp } = await import('sharp');
  const own = !browser;
  const b = browser ?? await launchBrowser();
  try {
    const { page, context } = await openPage(b, { url, width: 1440 });
    try {
      const e = await extractPage(page);
      let ogImageInfo = null;
      if (e.og.image) {
        try {
          const res = await context.request.get(e.og.image);
          const meta = res.ok() ? await sharp(await res.body()).metadata() : {};
          ogImageInfo = { ok: res.ok(), status: res.status(), width: meta.width ?? 0, height: meta.height ?? 0 };
        } catch (err) { ogImageInfo = { ok: false, status: 0, width: 0, height: 0, error: err.message }; }
      }
      const result = { url, focusKeyword, ...auditExtract(e, { focusKeyword, ogImageInfo }), extract: e };
      if (out) fs.writeFileSync(out, `${JSON.stringify(result, null, 2)}\n`);
      return result;
    } finally { await context.close(); }
  } finally { if (own) await b.close(); }
}

async function main(argv) {
  const a = {};
```

```js
export function recordAudit(themeDir, slug, auditFile) {
  const audit = JSON.parse(fs.readFileSync(auditFile, 'utf8'));
  let status;
  updateState(themeDir, (s) => {
    const p = s.pages.find((x) => x.slug === slug);

    p.seo = { ...(p.seo ?? {}), audit: { pass: audit.pass === true, file: auditFile, at: new Date().toISOString() } };
    if (audit.pass === true) p.status = 'done';
    status = p.status;
  });
  return { pass: audit.pass === true, status };
}
```
